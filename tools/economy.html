Economy Sandbox

Format
  • resources: { "id", "name", "color", "volume", "icon" }. Volume is how much storage space one unit takes (default 1). icon is optional: a small pixel-art image as a data:image/png;base64,… URL (10×10 works well); without one, the color is used.
  • recipes: { "id", "name", "time" (seconds), "inputs": { resourceId: amount }, "outputs": { resourceId: amount } }. Empty inputs make an extraction recipe (mines, quarries).
  • buildings: { "id", "name", "color", "recipes": [recipeIds], "storage", "cost", "speed"? }. cost is { resourceId: amount }, paid from your warehouses when you add the building and refunded when you remove it. storage is the total volume its output can hold; a recipe only starts if its outputs fit. Add "splitter": true (1 in, ports out; sends to production first, then warehouses, then incinerators) or "merger": true (ports in, 1 out) for logistics buildings. Every connector takes one conveyor; ports also sets how many inputs a warehouse or incinerator has. Add "trash": true for a building that destroys anything piped into it (it only gets items nothing else wants). Add "sink": true for a building that accepts and stores anything (warehouse); its storage is the warehouse capacity (leave it out for unlimited).
  • startingResources: { resourceId: amount }, your starting capital. It's put in the factory's first warehouse (a free one is placed if there is none) whenever the factory is loaded.
  • Map: settings.map is { "cols", "rows" }. A resource with "onmap": true is scattered over the map as deposits cells (default 3). A building with "onDeposit": true must stand on a deposit, and runs whichever of its recipes outputs that deposit's resource.
  • Game files: this is the format of the game's economies/*.json. Open file… loads one, Download saves it back. The game adds fields the sandbox keeps but ignores: id, name, sprite, key, size, work, kW, crew, insideRing, range, and buildings with "belt": true or "pole": true. The game writes "onMap": true with "fields": { "count", "tiles", "perTile", "distance" }; the sandbox reads count as the number of deposits.
  • settings: beltSpeed (px/s), itemSpacing (px between items on a belt), bufferSize (how many of each input a building holds), defaultStorage (output storage for buildings that don't set their own).
Applying keeps your factory layout; buildings or recipes you removed drop out of it.
